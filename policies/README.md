# Walking policy

`unitree_h1_motion.pt` is Unitree's pretrained H1 walking policy, copied unchanged from
[unitree_rl_gym](https://github.com/unitreerobotics/unitree_rl_gym) (`deploy/pre_train/h1/motion.pt`).

M0NARCH runs it with NumPy (`h1_policy.py`, no PyTorch) in `physics_walk.py`.
